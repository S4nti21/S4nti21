## Proyectos destacados

### 📄 RDAM — Sistema de gestión de certificados de deuda alimentaria

Digitaliza de punta a punta un trámite que hoy se hace en papel: el ciudadano se acerca a una ventanilla, paga en efectivo y vuelve otro día a retirar el certificado. RDAM reemplaza todo ese circuito por un flujo online con trazabilidad completa de cada paso.

**Flujo:** el ciudadano radica la solicitud → paga el arancel por una pasarela de pago externa → un operador la revisa desde su bandeja de trabajo → la emite o rechaza → el ciudadano recibe el certificado por email.

**Roles y permisos:**

| Rol | Qué puede hacer |
|---|---|
| Ciudadano | Radicar solicitudes, pagar el arancel, recibir el certificado |
| Operador | Tomar solicitudes de la bandeja, emitir o rechazar |
| Administrador | Todo lo anterior, más gestión de usuarios, arancel y auditoría |

<details>
<summary><b>Stack del proyecto</b></summary>
<br/>

|---|---|

| Pasarela de pago | Node.js + Express (simulador) · AES-256-CBC · webhook firmado con HMAC-SHA256 |
| Infraestructura | Docker Compose (4 servicios) · nginx · GitHub Actions |
